## Amazon Rekgnition

- Find objects in images and videos using ML.
- Create database of familiar faces.
- Content Moderation: Detect inappropriate content, set a minimum confidence threshold flag sensitive content for manual review.

## Amazon Transcribe

- Convert speech to text using automatic speech recognition.
- Automatically remove Personally Identifiable Information (PII) using Redaction.
- Automatic Language Identification.

## Amazon Polly

- Text into speech

### Lexicon and SSML

- Upload Lexicons and use them in the SynthesizeSpeech operation.
- Generate speech from documents marked up with Speech Synthesis Markup Language.

## Amazon Translate

- Natural language translation
- Allows to localize content, such as websites and applications.

## Amazon Lex and Connect

- Amazon Lex: Automatic Speech Recognition, Natural Language Understanding
- Amazon Connect: Virtual Contact Center, Integrate with CRM or AWS.

## Amazon Comprehend

- For NLP.
- Fully managed, serverless
- Uses ML to find insights and relationships in text.

## Amazon Comprehend Medical

- Detects and returns useful information i unstructured clinical text.
- Uses NLP to detect Protected Health Information.

## Amazon SageMaker AI

- Fully managed service to build ML models.

![](./assets/Pasted%20image%2020251004094309.png)

## Amazon Kendra

- Fully managed document search service powered by ML.
- Natural language search capabilities.
- Learn from user interaction/feedback.
- Manually fine-tune search results.

## Amazon Personalize

- Fully managed ML service for personalized recommendations.
- Same tech used by Amazon.com.

## Amazon Textract

- Automatically extracts text, handwriting from any scanned document using AI/ML.
