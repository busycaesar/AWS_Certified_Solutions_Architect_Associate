## 6 Pillars

1. Operational Excellence
2. Security
3. Reliability
4. Performance Efficiency
5. Cost Optimization
6. Sustainability

- Pillars are for synergy and not for balance.

## AWS Well-Architected Tool

- Tool to review the architectures against 6 pillars and adopt best practices.
  - Select workload and answer questions.
  - Review answers against 6 pillars.
  - Obtain advice.
