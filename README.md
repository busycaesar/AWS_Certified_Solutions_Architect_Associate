# AWS Certified Solutions Architect Associate

## Description

This repository contains my personal notes, summaries, and key concepts while preparing for the [AWS Certified Solutions Architect - Associate (SAA-C03)](https://aws.amazon.com/certification/certified-solutions-architect-associate/) certification. These notes are inspired by the [Ultimate AWS Certified Solutions Architect Associate 2025](https://www.udemy.com/course/aws-certified-solutions-architect-associate-saa-c03) Udemy course, which I highly recommend for anyone preparing for this certification.
